# Lottery Helper · 彩票助手

快乐8 / 双色球 / 大乐透 的选号 + 走势分析静态站点（GitHub Pages）。

## 文件结构

```
index.html              主入口（三个 iframe 标签页）
Klb.html                快乐8：区间选号 / 模拟选号 / 走势 / 分布 / 尾号 / 验算
Ssq.html                双色球：分区选号（红球三区 + 蓝球不分区）/ 走势分布
Dlt.html                大乐透：走势分布
mobile.css              手机端适配样式（桌面端零改动）
mobile.js               手机端运行时补丁（实测期号列宽度，给分区统计列定位）
data.js                 开奖数据统一加载器（本地文件 + 在线源自动合并取最新）
data/kl8|ssq|dlt.json   开奖数据（最新在后，含 100 期）
data/kl8|ssq|dlt.js     同数据的 JS 版本，页面用 <script> 加载，file:// 双击也能跑
tools/fetch_data.py     抓官方接口、刷新 data/ 的脚本
.github/workflows/update-data.yml  每天定时跑上面的脚本
```

## 数据来源

| 彩种 | 接口 |
|---|---|
| 快乐8、双色球 | 中国福彩网 `cwl.gov.cn` 官方开奖查询 |
| 大乐透 | 中国体彩网 `webapi.sporttery.cn` 官方历史开奖 |

页面加载顺序：`data/*.js`（同源静态文件）→ 浏览器 localStorage 缓存 → 在线接口。
同一个期号以静态文件为准，最终按期号取最新的一期，状态栏会显示「已更新至 XXXX 期（日期）」。

> 早先版本用的是第三方接口 `api.huiniao.top`，该接口 2026-11-14 起停更，所以快乐8 一直显示旧号码。

## 更新数据

本地（推荐，国内网络直连官方接口最稳）：

```bash
python tools/fetch_data.py
```

跑完会重写 `data/*.json` 和 `data/*.js`，刷新页面即可看到最新一期。

云端：GitHub Actions 每天北京时间 22:40 自动跑一次（见 workflow），需要仓库允许 Actions 写权限。

## 双色球选号说明

- 红球按 3 个区分：一区 01-11、二区 12-22、三区 23-33；用「区比」控制每区出几个（默认 2:2:2，合计必须为 6）。
- 蓝球 01-16 不分区，可多选；不选则从全号池按权重抽取。
- 单击选号，双击设胆（红球胆码在该区必出；蓝球定蓝则所有注共用）。
- 生成策略：均衡（热号 + 冷号回补） / 追热 / 补冷 / 纯随机，权重来自近 60 期出现频率与遗漏期数。
- 结果用纯文本显示（`01,05,16,18,24,27 + 04`），不画球；每注可单独复制，也可「复制全部」一次拿走（每行一注）。
- 支持批量注数、去重、下载 TXT、「历史验算」（近 30 期逐期算奖级与盈亏）。
- 验算结果是**可折叠面板**：标题行直接给出投入 / 中奖 / 盈亏 / 中奖注数，点开才看奖级统计与逐注明细。

## 手机端适配

`mobile.css` 统一处理，桌面端完全不受影响（断点 768px / 430px）：

- 顶栏、卡片、内边距整体收窄，把首屏留给内容；Ssq 的智能选号/走势分布做成等宽分段控件。
- 标签栏改为**单行横滑**（不换行、隐藏滚动条），切换后当前标签自动滚入视野。
- 号码球改成自适应网格：快乐8 一区 10 个号一行排满，双色球按屏宽 8~9 个一行。
- 快捷按钮全部 ≥42px，主操作（生成号码 / 智能选号）独占一行 50px 高。
- 表单控件统一 16px，避免 iOS 聚焦时页面被放大；`viewport-fit=cover` + `env(safe-area-inset-bottom)` 适配刘海屏。
- 宽表格（走势 / 分布）不再内部上下滚动，改为整页滚动 + **期号列与分区统计列同时吸附左边**
  （分区统计的吸附位置由 `mobile.js` 实测期号列宽度写入 `--dist-pw`，不会与期号列错位重叠），
  并给出一条「左右滑动」提示。
- 双色球生成号码后自动滚动到结果；触摸设备关掉 hover 位移，避免点一下位置乱跳。
- 首页在手机上不再嵌 iframe（双标题栏 + 嵌套滚动），改成三个入口大卡片直接进入子页。
